# مفتاح العام الجديد — النسخة المصححة للآيباد (بدون مجلدات)

هذه النسخة مصححة بالكامل وتحتوي كل الملفات في مستوى واحد.

طريقة الرفع:
1. فكّي الضغط.
2. في مستودع GitHub احذفي/استبدلي الملفات القديمة.
3. ارفعي جميع الملفات الموجودة داخل هذه الحزمة دفعة واحدة إلى جذر المستودع.
4. يجب أن يكون index.html ظاهرًا مباشرة في الصفحة الرئيسية.
5. انتظري GitHub Pages دقيقة أو دقيقتين ثم أعيدي فتح الرابط.

تم تعديل مسارات الصور والأيقونات لتعمل بدون مجلد assets.
تم تغيير إصدار Service Worker حتى لا يستخدم المتصفح النسخة القديمة المخزنة.
