# مفتاح العام الجديد — النسخة المحسنة v5 للآيباد

نسخة بدون مجلدات، جاهزة للرفع مباشرة إلى جذر مستودع GitHub Pages.

## التحسينات
- إضاءة دائمة لجزء المفتاح عند إكمال كل محطة.
- إضاءة الطريق والمدرسة عند بدء الرحلة.
- مشهد ختامي كامل عند إنجاز 5/5 مع إضاءة المفتاح والطريق والمدرسة.
- زر شهادة الإنجاز مباشرة بعد المشهد الختامي.
- زر تثبيت ظاهر في الواجهة الرئيسية.
- زر بيانات الطالبة لتعديل الاسم أو بدء رحلة جديدة.
- تحديث Service Worker إلى v5 لتقليل مشكلة ظهور النسخة القديمة من الكاش.

## الرفع
فكي الضغط ثم ارفعي كل الملفات الموجودة داخل الحزمة إلى الصفحة الرئيسية للمستودع، بحيث يظهر index.html مباشرة في جذر المستودع.
